`ZLang HDL` is the name used to identify this open-source project. This policy
does not state that the name or any logo is registered in any jurisdiction.

## Uses that do not require permission

You may:

- identify an unmodified distribution accurately as ZLang HDL;
- make truthful, descriptive references to ZLang HDL in documentation,
  tutorials, reviews, benchmarks, compatibility statements, integrations, and
  interoperability testing;
- describe a modified distribution or fork as "based on ZLang HDL", provided
  the modification and lack of project endorsement are clear; and
- use the unmodified project name where technically necessary to describe
  compatible source files, commands, formats, or APIs.

These permissions do not allow a use that suggests sponsorship, certification,
official status, or endorsement by the ZLang HDL project or its maintainers.

## Uses that require permission

Please obtain written permission before using the ZLang HDL name or any project
logo as the primary brand for a separate product, hosted service, company, or
organization. In particular, do not use names such as "Official ZLang",
"ZLang Enterprise", "ZLang Professional", or "ZLang Cloud" for an unrelated
or modified offering in a way that could imply it is produced or endorsed by
this project.

Modified distributions must choose sufficiently distinct branding and state
prominently that they are modified. They may still make the truthful
descriptive statement that they are based on ZLang HDL.

For a public permission request or a question about a proposed use, open an
issue in the project repository. Security reports must instead follow
[SECURITY.md](SECURITY.md).
