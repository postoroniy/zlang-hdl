# ZLang HDL syntax support matrix

Canonical implementation-selection markers: `implement`, `choice`.

Implementation selection uses the canonical `implement` form for compiler-
discovered candidates and `choice` for user-supplied alternatives. The retired
scalar `pipeline(auto)`, `architecture(auto)`, and `explore` spellings are
migration diagnostics; only protocol `transform pipeline(auto, ...)` remains
source syntax.

This matrix is the executable-language companion to the parser and the
repository-owned VS Code grammar. Highlighting is lexical only; it does not
prove that a name, type, width, domain, or connection is semantically valid.
Direct SystemVerilog is the sole supported production backend; its exhaustive
current corpus is documented in [`direct-systemverilog.md`](direct-systemverilog.md).
Clash is retired and removed from the compiler, public CLI, package, default
tests, CI, and release acceptance.

`zlang.public_capabilities.CAPABILITY_REGISTRY` is the machine-readable source
for public capability context, semantic status, backend-independent IR,
simulator/direct-SV/formal coverage, executable witness, and current
limitations. Registry tests compile
every advertised witness. `examples/all_syntax.zhl` is a representative language
tour, not a substitute for that phase-specific capability record.

| Source form | Status | Canonical meaning | Executable top/test | Backend boundary |
| --- | --- | --- | --- | --- |
| `module`, domain-qualified `in`/`out`, `clock`, `reset`, `async reset`, module `where` | supported/bounded | typed module/domain declarations; adjacent `clock clk reset rst` is the same pair as the multiline spelling; `async reset` means asynchronous assertion with fixed two-edge synchronized release; each stateful entity resolves one stable domain identity | `AllSyntax`, `AsyncResetSyntax`, `MultiClockStateful`, physical-domain/formal-domain tests | Direct SV emits independent state processes and one reset conditioner per applicable domain. Power-on reset, implicit reset crossing, CDC/reset refinement, elastic equivalence and incompatible target primitive routes fail closed |
| `type Alias = T`, `import std.*`, `import module as name` | supported | type aliases normalize to canonical types; qualified logical imports resolve type/function/struct-constructor members and erase the source-local qualifier before canonical IR | fixed/complex and bus examples; qualified-import tests | import aliases are not runtime namespaces, do not re-export transitive declarations, and provide no wildcard or member-renaming syntax; std resolution cannot escape the shipped library root |
| module/function `type`/integer parameters, exact typed constants, and static function references | bounded supported | one deterministic specialization identity includes canonical type/value content plus the exact pure callee identity; constant/callable actuals are named | FFT stage, generic ROM/table and callable-parameter tests | compile-time only; constants are exact recursively bit-packable non-enum values; callables are pure named functions, not stored function pointers, closures, or runtime dispatch |
| `inst`, concise child declarations, inline bindings, compile-time instance arrays | bounded supported | one specialization may have multiple distinct physical `ElaboratedInstance` identities; structural indices are compile-time, while `lane[select].output` is a read-only mux over exact bit-packable wire outputs and never a dynamic instance | M40 composition; scalar/RV/storage `.zhl` witnesses; aggregate, mixed-port, scheduled-state, nested, request/response, and runtime-output-selection integration tests | one-dimensional scalar combinational/sequential arrays, aggregate scalar outputs, mixed scalar+RV arrays, storage-only FIFO/memory/ROM arrays, scheduled FIFO plus ordinary rule/register state, bounded nested same-domain scalar/direct-ready-valid hierarchy, and first-level in-order request/response arrays are supported. Runtime-selected inputs/protocols, legacy global storage plus user state, out-of-order or nested RR, other non-RV protocols, nested storage/CSR/aggregate protocols, and CDC arrays fail closed |
| named `interface Ifc<...> { ... }`, `module M<...> : Ifc<...>` | supported | exact nominal/applied `ModuleSignature` over parameters, scalar/aggregate ports, domains, and optional timing; no behavior or implementation selection | named-interface tests | semantic/canonical metadata reaches direct-SV; request/response roles fail closed |
| `extern module M : Ifc { model fn_name }` | bounded supported | exact scalar-wire `ModuleSignature` plus a pure ZLang function as backend-independent semantics; physical HDL is a separate hash-validated mapping | external-module parser/semantic/canonical/simulator/direct-SV tests | direct SV requires an exact `ExternalPhysicalMapping`; no parameters, state, protocols, clocks, arrays, or inline HDL |
| `bit`, `uN`, `sN`, `uint<N>`, `sint<N>`, `bits<N>` | supported | canonical scalar hardware types | `ScalarSyntax` | simulator and direct-SV |
| `fixed<W,F>`, `ufixed<W,F>`, `SF8.8`, `UF8.8`, `_Sat` forms | supported | canonical fixed-point type and explicit overflow policy | `FixedSyntax` | simulator and direct-SV for exercised subset |
| `vec<N,T>`, vector literals, `repeat(value)`, static `values[first..past_last]`, structs, field/index access, struct construction/update/destructure | supported | `[a,b]` and contextual `repeat(value)` normalize to existing vector-generation IR; a half-open static vector range lowers to ordered compile-time element references; `value with { ... }` rebuilds the same nominal struct while retaining omitted fields; exhaustive immutable `Struct { ... } = value` binds every field once; structural `==`/`!=` requires exact matching aggregate types | `FunctionalSyntax`, `StructSyntax`, `ConciseLoweringSyntax`, `AllSyntax` | direct SystemVerilog for exercised subset; vector literals/ranges are non-empty and exact, and destructuring may not omit, repeat, rename, or shadow fields |
| `x[MSB:LSB]`, `bits_value[i]`, `zeros<N>`, `ones<N>`, `concat`, `reshape`, `bitcast`; low-level `pack`, `unpack` | supported | slices return raw bits; single-bit selection returns `bit` with LSB-zero packed numbering and a compile-time-proven index; non-vector representation concat and explicit bitcast use MSB-first canonical representation; homogeneous vector concat/reshape preserve outer-to-inner collection order; exact width/leaf types only | `AllSyntax`, concise bit/collection tests | simulator and direct-SV; runtime packed-bit selection, zero/unresolved widths, heterogeneous concat, runtime reshape, unequal width, and enum bitcast fail closed |
| `enum State { ... }`, `enum E : bits<W> { A=... }`, qualified members, exhaustive enum `switch` | supported | nominal ordinal or explicitly encoded sparse type; safe raw boundary uses `enum_encode`, `enum_valid<T>`, and total `enum_decode<T>(raw,fallback)` | APB bridge, enum and encoded-enum tests | simulator and direct-SV; top enum inputs, implicit integer conversion, and `unpack<Enum>` fail closed |
| `union Message { ... }`, named constructors, exhaustive pure `match` | supported bounded slice | nominal source-ordered tag plus maximum-width payload; match lowers to typed tag `Switch` and exact field projections | `TaggedUnionExample`, tagged-union tests | simulator and direct-SV; fields are flat scalars, top union inputs/raw decode/operators/generic unions fail closed |
| decimal, hexadecimal, binary integers, syntactic negative integers, and exact decimals | supported | arbitrary-precision literal value; radix/leading zeros are not identity; unconstrained integers use minimum exact unsigned/signed width and direct literals may use an exact fitting typed boundary | `AllSyntax`, `FixedSyntax` | direct-SV; compound expressions are never contextually resized |
| `//` and non-nested `/* ... */` comments | supported | lexical whitespace | parser tests | parser/editor only |
| pure `fn`, generic structs/functions/operators; immutable body bindings and final result expression | supported | exact call-site inference, context-independent explicit or inferred return signatures, declaration-order-independent calls, monomorphized typed value IR; bare sequential bindings are inferred and normalized away; binary `+`/`-`/`*` and unary `-` nominal overloads; a generic may invoke an exact `operation : fn(A) -> B` parameter selected by `operation=fn name` | `AllSyntax`, `StructSyntax`, generic/operator, typed-static-parameter and language-coherence tests | direct-SV where concrete; recursive inference/calls, capture, mutation, `let`, `const`, `return`, callable values, and runtime dispatch are rejected |
| declaration-only and declaration-order-independent source units | supported | top-level declarations are collected before semantic use; declaration-only stdlib units contribute types/functions without becoming hardware children | language-coherence and stdlib resolver tests | compile-time organization only; a runnable compilation still selects a concrete module top |
| unary `-`, bit-only `!`, exact-width `~`, `?:`, `mux`, `switch`, arithmetic/bitwise/shift/comparison | supported | exact typed value expressions; unary `-` is numeric or a resolved nominal overload; runtime `!` requires `bit`; `~` preserves the exact scalar bit width and never resizes | `ScalarSyntax`, generic/operator tests | simulator and direct-SV |
| `generate`, `map`, `sum`, `reduce`, `dot` | supported | bounded functional IR; eligible large pure regions use compact `FunctionalRegion`/exact reduction-plan storage with unchanged typing and source order | `FunctionalSyntax`, IFFT64 N=64 whole-vector semantic reference, N=8/N=16 whole-vector backend witnesses; production streaming SDF is a separate hierarchical design | logical generation budget is 4096; no runtime loop, reassociation, moved quantization, or claim that the whole-vector N=64 reference is emitted as one RTL datapath |
| `truncate<N>`, `extend<N>`, contextual `truncate(expr)`/`extend(expr)`, `quantize` | supported | explicit typed conversion; contextual width is accepted only at an exact declared boundary and normalizes to the explicit-width typed IR | `FixedSyntax`, `ConciseLoweringSyntax` | simulator and direct-SV; inferred locals, nested operands and cross-family conversions fail closed |
| compile-time `if`, `generate` bounds/index arithmetic, `length`, `floor_log2`, `ceil_log2`, `index_width`, shape and deterministic real intrinsics | supported | bounded specialization-time selection/evaluation; defaults see only earlier parameters; compile-time iterators use mathematical integers; non-integral reals require explicit fixed quantization | `CompileTimeSyntax`, `ConciseLoweringSyntax`, compile-time generation tests | elaboration before backend; no runtime real hardware or forward-reference defaults |
| `/`, `&&`, `||` in compile-time expressions; `&&` in frozen `equiv` guards | context-bounded | compile-time integer/real or frozen guard semantics only | compile-time and M27 guard tests | not runtime divider/general Boolean hardware operators |
| domain-qualified registers, runtime-indexed `reg vec` element update, delays, fixed `pipeline(N) @clk`, recursive action `when`/`else when`/`else`, `rule R @clk`, `priority` | supported | each state/action group has one owner; recursive selection retains one `Rule` and one `ActionGroup`; all guards/operands use that domain's pre-edge snapshot and accepted effects commit atomically at its edge. Schedulers and conflicts are per-domain; static values remain neutral; an illegal storage action does not fall back and a pipeline cut never authorizes CDC | `MultiClockStateful`, `StateSyntax`, `ConciseLoweringSyntax`, nested-action and multi-clock simulator/RTL tests | simulator and direct-SV. Mixed dynamic provenance, hidden-local crossings and cross-domain priorities fail closed. There is no cross-clock atomicity or automatic CDC |
| `fsm state : Enum = Initial { ... }` with optional `@clk`, inferred `fsm state @clk = Enum.Initial { ... }`, `hold`, guarded/unconditional `->` transitions | supported concise syntax | the qualified initial member may infer the nominal enum type; both forms lower to one domain-owned enum register plus ordinary domain-owned rules and explicit priority before canonical/backend IR | source-authored APB, `FsmSyntax`, `IeeeIFFTInputStrip`, multi-clock FSM tests | no backend FSM node, hidden source-order priority, cross-domain transition, or runtime procedural `if` |
| `timing { latency N ii 1 }` | supported | one exact module contract over every scalar wire output; immutable public behavior, not an exploration request | `ScalarSyntax`, timed hierarchy tests | timeless/known/unknown analysis; positive latency requires one clock/reset domain; protocol and state-dependent outputs fail closed |
| `fifo`, `memory : mem<T,N>`, `memory : async_mem<T,N>`, initialized `rom` (optionally `@clk`); generic storage wrappers | supported bounded | legacy `mem` remains 1R1W; named `read_port`/`write_port`/`read_write_port` give up to eight same-domain logical ports with complete multiwrite priority; bounded planning selects exact target storage, 1W+nR replication, or a register/mux network. `async_mem` is exactly one write port plus one latency-one read port in distinct domains. Optional `init VALUE` is one exact compile-time word applied uniformly: clear-on-reset generic storage restores it, while preserved FPGA RAM treats it as power-up/bitstream initialization. Arbitrary positive bit-packable widths retain `ceil(W/8)` masks and independent cell/read-result reset policies | `FifoSyntax`, `MemorySyntax`, `PortedMemorySyntax`, `AsyncMemorySyntax`, `RuleLocalMemory`, multi-clock/ported-memory tests and generic wrappers | simulator and direct-SV; foreign controls and implicit CDC fail closed. Normal FIFO never becomes CDC; stream crossing remains explicit `async_fifo`. No full writable image, asynchronous 2RW, mixed port widths/depths, automatic banking or unbounded fallback |
| ready/valid, credit, request/response, packet, aggregate protocols | supported | typed endpoint ownership plus read-only properties such as `.transfer`, credit counts, and FIFO/channel observations | protocol tops | direct-SV for the documented corpus; feature-specific boundaries fail closed |
| imported `AXI4BurstSubset<AW,DW>`, read/write views, `AXI4BurstReader`/`AXI4BurstWriter` | bounded supported | ordinary source-owned five-channel ready/valid schema and single-outstanding, full-width incrementing helpers; `len` is beats minus one and counted completion retains exact R/W backpressure and reset epochs | `ZtpuAxiBurstReader64x32`, `ZtpuAxiBurstWriter64x32`; semantic/canonical, simulator and direct-SV/Verilator | validated profile is 64-bit byte addresses and 32-bit data with 1–256 beats; no compiler/backend AXI dispatch, IDs, WSTRB, burst-kind/sidebands, multiple outstanding operations, UB-DMA chunking, fences, CDC, or implicit adaptation |
| imported `AHBLite<AW,DW>` and `AHBLiteToRegBus<AW,DW>` | bounded supported | ordinary source-owned single-manager AHB-Lite schema; pipelined address/control and write-data phases, one outstanding full-width RegBus request, wait states, two-cycle ERROR, and active-low async-assert/two-edge-sync-release reset | `AhbCsrTop`; semantic/canonical, independent oracle, semantic simulator and direct-SV/Verilator | aligned full-width transfers only; byte-addressable power-of-two `DW` 8…1024; connected sequential targets must share the exact reset contract; no compiler/backend AHB dispatch, subword strobes, multi-manager arbitration, SPLIT/RETRY, CDC or new formal family |
| `input -> output { transform pipeline(auto, ...) { kernel(input.payload) } }` | bounded | one compiler-owned globally stalled M31 product-reduction pipeline; `minimum_unstalled_latency`, `ii_no_stall=1`, capacity and variable wall-clock latency stay explicit | `ElasticPipelineAuto` | simulator and direct-SV; existing M35 RV stability only, no M36 or required M39 route |
| `connect`, option-free named-transform chains, adapters, arbitration, CDC | supported | explicit hierarchy/protocol/CDC IR; `sync_level`, `pulse_toggle`, `handshake`, and `async_fifo` terminate one synchronous provenance and create a destination-domain value | `CdcSyntax`, `StatefulSyncLevel`, `MultiClockStream`, aggregate/structural tests | no implicit adaptation or CDC; CDC is an optimizer/timing/scheduler barrier; multi-bit changing data is rejected by `sync_level` |
| `csr bank @BASE @clk` and access policies (`rw`, `ro`, `wo`, `w1c`, `pulse`, `reserved`) | supported | typed CSR register/field state with one exact clock/reset owner | `CsrSyntax`, multi-clock CSR/state test | blocks sharing the canonical CSR access ABI share one domain; values entering another domain require explicit CDC |
| named `assert`/`cover`; scoped `contract` with `require`/`assert`/`ensure`/`cover`; legacy `assume`/`guarantee` | supported bounded verification UX | verification-only `VerificationScope`/goal/requirement overlay; safety lowers to existing M35 `FormalProperty`, reachability to separate `CoverProperty`; legacy forms normalize into the module-global scope without changing hardware identity | editor verification witness; parser/semantic/monitor/bundle, exact physical-domain routing, and real SBY/Z3 tests | same-cycle clocked predicates only; `ensure` observes a public implementation output, `require` is environment-owned, covers report `witnessed` or `bounded_unreached`; each plan/job/result retains its exact `ClockDomain` and compatible BackendArtifact physical identity. Raw `physical_reset` and effective `trace:reset` remain distinct; no cross-domain temporal relation is inferred, and missing/incompatible bindings or unsupported domain contracts fail/skip explicitly |
| `equiv` with frozen M27 guards | supported | bounded typed rewrite declaration over the accepted exact scalar e-graph set; arithmetic rewrites preserve the complete canonical signature | top-level `or_zero`, `ShiftMultiply`, arithmetic e-graph tests | no state/timing/resources in egglog; no ordinary carry-growing reassociation or movement across fixed conversion |
| `pipeline(N)` | supported | exact latency/II contract; supported pure scalar DAGs receive deterministic operation stages, reconvergence balancing and one shared `ScheduledValueGraph` | `GeneralExpressionPipeline`, FIR/FFT arithmetic witnesses | direct-SV production lowering; targetless structural cost or Xilinx 7-Series DSP48E1 covering; unsupported effects fail closed |
| `implement { ... intent { ... } }` plus `choice`; target/resource declarations | supported | one normalized `ImplementationRequest`/implementation-site IR; complete candidates include exact value, schedule and resource graph | `ExplorationSyntax`, FFT signed-product and implementation-intent tests | packaged QoR is hash-bound; unknown timing cannot satisfy Fmax; retired scalar forms produce migration diagnostics |
| logical imports from pinned path/Git projects | supported | `zlang.toml` plus `zlang.lock` fixes module index, transitive hashes, and full Git revision for offline compilation | project/dependency fixtures and 802.11 project | fetching occurs only through explicit lock update; compile is read-only and rejects dirty/mismatched content |
| `namespace`, source-level import revisions/wildcards/re-export, registry/semver resolution | deferred | broader user package language/resolver | none | use exact logical imports, optional local qualifiers, or locked project dependencies |
| named `zlang.toml` implementation profiles and `--profile` | supported tooling | source/CLI/profile policy normalizes to one `ImplementationRequest` per semantic region | profile tests | no implicit backend substitution; conflicting normalized policies fail closed |
| `char`, `string<N>`, character/string literals, structural tuples `(T,U)`, `(a,b)`, `pair[0]`, flat `(a,b) = pair` | supported bounded slice | `char`/`string<N>` erase exactly to `u8`/`vec<N,u8>`; tuples are ordered structural aggregate IR with arity 2..8 and component zero at the packed MSB | `TextTupleSyntax` | simulator and direct-SV; strings are non-empty fixed byte vectors, tuples use literal zero-based projection and flat immutable destructuring only; Unicode, dynamic strings, runtime tuple indexing and nested patterns fail closed |
| runtime procedural `if`, `else if`, `match`, `return`, `comb`, `seq` | deferred | imperative control-flow syntax | none | use expressions or `switch` for values and recursive atomic `when`/`else when`/`else` for action selection; compile-time `if` remains elaboration-only |
| `const`, `let`, `var`, C-style `input`/`output`, semicolons | not planned | redundant or non-ZLang binding spellings; no new mutable/local model planned | none | use immutable typed bindings and ZLang declarations |
| liveness/eventuality/fairness, temporal sequences, arbitrary SVA/SMT, source M36 controls | deferred | would require separately frozen temporal/equivalence semantics and honest tool-result meanings | none | use named same-cycle safety goals, bounded `cover`, and compiler-owned M36 routes; M38 is retired and SuProve is not currently available |
| `pi`, `sin`, `cos`, mathematical `log2`/`log` calls | supported | deterministic compile-time real intrinsics, explicit fixed quantization only | compile-time generation and ROM tests | no runtime real hardware; generated constants may initialize `rom` |
| `--simulation-state-bundle` (tooling; no source syntax) | bounded supported | selected-IR-bound catalog over bit-packable registers, vector registers, writable-memory contents, and one-cycle memory read latches; direct-SV VPI locators bind to one unchanged artifact | ZTPU two-chunk replay and real Verilator VPI tests | one exact clock/reset domain and generic direct-SV only; arbitrary-width elements use 32-bit raw-word arrays; target-mapped state, FIFO/CSR/protocol internals, CDC and synthesized preload ports fail closed |
| full AXI4 IDs/multiple outstanding/general burst attributes, synthesizable writable-memory initialization, asynchronous 2RW/mixed-width/unbounded memory, automatic banking, CDC extensions | deferred | later library/design coverage | none | the narrower no-ID ZTPU burst profile is supported; immutable synchronous ROM, bounded ported writable memory, exact 1W1R `async_mem`, and separate simulation-only state access are supported |
