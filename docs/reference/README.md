# Previous PDF chapter paths

These paths are compatibility navigation pages, not separately maintained
chapters. The three [manual entrypoints](../README.md) link to canonical topic
guides shared by Markdown and PDF. [The manifest](../manuals.toml) owns book
membership, chapter order and PDF names. There is no additional omnibus PDF.

The host-only builder uses the same renderer, styling and example checks for
all three books. Public `make community-pdf-check` validates the complete
reviewed set against release metadata. Hash checks are not visual review.
